## Browsers and harness

- Firefox and WebKit (suite is Chromium-only).
- HTTPS test server (`httpsServer`, ignoreHTTPSErrors, client certificates). Blocks official SSL `page.goto` cases and autowaiting “links which do not commit navigation”.
- `waitForURL` / `route` globs are not resolved against context `baseURL`.
- URL matches: regex (`UrlMatchRegex`) and predicate (`UrlMatchPredicate`) are supported for routes and waits (`UrlMatch`, see QUESTIONS.md for the engine and escape limits). Glob remains the default. Still open: `URLPattern`, and regex-specific cases that depend on lookaround.
- IndexedDB and WebAuthn credentials on `StorageState`.
- `unrouteAll` `wait` / `ignoreErrors`.
- HAR, video, screencast, WebSocket routing. Tracing is partly ported (`tracing`): start / stop / chunks / groups and zip entry names only. Still open: trace content checks (action titles, sources, resources, network), `tracesDir` launch option, APIRequestContext tracing (no `request.tracing` in this client), and dialog-blocking cases that need trace content. Global `APIRequest.newContext` / `global-fetch` covers the HTTP cases (methods, dispose, userAgent, timeout, extra headers, credentials, empty body, abort, redirects, JSON bodies, maxRedirects, failOnStatusCode). `global-fetch-cookie` covers path filtering, localhost secure cookies, expiry/max-age, Set-Cookie overrides, and storageState round-trip (not IndexedDB or file path). Still open: HTTPS/`ignoreHTTPSErrors`/`securityDetails`, DNS `__testHookLookup` (custom cookie domains), brotli Range, connectOverCDP, bool/numeric params, `close` reason on fetch errors, JS `inspect`/`toJSON()` client serialization. `response.serverAddr` is wrapped but Playwright 1.61.1 omits it when Node happy-eyeballs has not set `remoteAddress` yet. `browsercontext-fetch-algorithms` covers gzip/deflate/br decompression including missing Content-Length, chunked, and empty bodies.
- Screencast gaps that need more than the driver: `artifactsDir` launch option and `recordVideo` context option (not exposed by this client), and webm frame decoding for the "empty video" and "dispose stops recording" cases (no decoder in the harness). Ported screencast cases are in `test/Playwright/ScreencastSpec.hs`.

## Assertions

Skipped `tests/page` specs that depend on `expect` (no Haskell spec, not started; expect-boolean is partly ported, see below): expect-builtins, expect-matcher-result, expect-misc, expect-timeout, expect-to-have-accessible, expect-to-have-text, expect-to-have-value, expect-with-snapshot, locator-any-frame, page-aria-snapshot, page-aria-snapshot-ai, page-aria-snapshot-json, page-evaluate-world, to-match-aria-snapshot. `page-evaluate-callback` is not blocked on `expect`. It is ported in `test/Playwright/PageEvaluateCallbackSpec.hs` through `exposeFunction` and the evaluate family. Eighteen of its 23 upstream cases are ported. Skipped cases: 1 (no `exposeFunctions` evaluate option in Haskell), 3 (a whole-argument function, which Haskell cannot serialize), 6 and 7 (handles returned from callbacks; the callback returns only a serialized argument), and 22 (checks the internal `__pw_fn_` global name).
