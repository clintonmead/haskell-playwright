- **page-network-sizes:** `should work with 404 status code` failed once in a full run (30 s `WaitTimeout`). All six cases use `armRequest`. 5 of 5 reruns pass. `waitForRequest` still subscribes when its action runs, so `withAsync (waitForRequest ...)` keeps the race.
